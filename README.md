*** FILE SETUP ***
Download all necessary files into the same folder, including:
    clean.py
    details.py
    final_project.py
    merge.py
    test.py
    visualize.py

    diabetes.csv (obtained through github or linked instructions in report)
    insurance.csv (obtained through github or linked instructions in report)
    poverty.csv (obtained through github or linked instructions in report)

    test_diabetes.csv (obtained through github or linked instructions in report)
    test_insurance.csv (obtained through github or linked instructions in report)
    test_poverty.csv (obtained through github or linked instructions in report)

*** RUNNING CODE ***
To generate the visualizations included in our report, simply run final_project.py. 
clean.py, merge.py, and visualize.py contain helper functions that are imported 
into final_project.py. 

To test the functionality of the various helper functions, simply run test.py. 

To obtain the EDA details on the chosen datasets, simply run details.py.
